# MECHANICA · 物理教学工作台

浏览器里的 Agent 驱动物理沙盒工作台：真实刚体引擎（Rapier WASM）+ PBR 摄影棚渲染（three.js + HDRI + ACES）。
当前处于 **P0 通用工作台内核** 阶段：场景文档驱动、组件可增删改、真实物理演化、可保存恢复。
原固定轨道演示保留在 `classic.html`（见下）。

## 运行

物理引擎经 ES module 加载，必须走本地 http 服务（file:// 会被 CORS 拦）：

```
cd D:\mechanica-lab
python tools/serve.py            # 或 python -m http.server 8721
# 浏览器打开 http://127.0.0.1:8721          ← 工作台
#            http://127.0.0.1:8721/classic.html ← 原轨道演示（保留版）
```

## 工作台（index.html）

```
顶栏    新建 / 预置场景 / 保存 / 打开 / 撤销重做 / 移动·旋转 gizmo / 吸附 / 全局·顶·前·侧·聚焦
左栏    组件目录（球·方块·圆柱·斜坡·地面板）+ 场景对象大纲
中央    3D 视口：点选、gizmo 拖动、滚轮缩放、左键拖转视角
右栏    属性检查器 + Agent 解析（标签页切换）
底栏    运行 / 暂停 / 单步(1/120s) / 重置 / 时间倍率 / 模拟时间 / 选中对象读数
```

- 键盘：`Space` 运行/暂停 · `W/E` 移动/旋转 gizmo · `F` 聚焦 · `R` 重置 · `Del` 删除 · `Ctrl+Z/Y` 撤销重做 · `Ctrl+S` 保存 · `Ctrl+D` 复制
- 场景自动保存到浏览器 localStorage；保存按钮下载 `.mechanica.json`，打开按钮载入
- 编辑态改参数即时重建物理世界；运行态参数只读；重置 = 从场景文档全量重建回初始态

## Agent 题目解析（P1 切片，链路完整）

右栏"Agent 解析"标签：**上传或拍照**（getUserMedia 相机采帧）题图，可**框选题目区域**（解析只发送选区）→
面板顶部**"当前任务"阶段徽标**：未开始 → 图片就绪 → 解析中 → 待确认 → 已建场 → 已解释（状态机全链路）。
`POST /api/parse-question`（step-5-preview 视觉模型）→
结构化解析（题型/实体/物理量/单位/置信度/未知量/假设）→ 用户逐项检查修正 → 确认后经白名单 API 创建真实场景实体 →
运行真实物理 → **"运行并生成解释"**：轨迹采样后对照理论（确定性物理计算，非模型生成——理论 √(2g·Δh) vs 实测、
机械能漂移、假设核对、题目全长参考值）。

- **密钥纪律**：key 只在服务端（环境变量 `MECHANICA_STEP_KEY` 或未跟踪文件 `tools/server/step_key.txt`），前端代码/Git/日志零出现（check.py 有泄漏扫描红线）
- 无 Key 时可点"载入本地示例解析数据"（fixture，明确标注非真实模型输出）验证后续物理链路
- 解析给出的值带"题给"徽标，Agent 补的默认值带"默认"徽标；用户修改会记录进场景文档 `meta.corrections`
- 建场统一走 `window.MECH` 白名单 API（与组件目录同一路径），实体来源标 `agent`
- 摩擦按成对属性处理：模型标在球上或斜面上等效（取显式值最小注入两侧）

## 架构（src/engine/）

| 模块 | 职责 |
|---|---|
| `scene-doc.js` | 版本化 JSON 场景文档（实体/变换/物理/材质/来源），快照式撤销重做 |
| `registry.js` | 组件注册表：几何构建 + 碰撞构建 + 参数 schema（单位/范围/校验）。新组件只在此登记 |
| `runtime.js` | 文档 → three 网格 + Rapier 刚体全量重建；固定步长 1/120s；每帧步数上限 + 背压丢弃；碰撞事件；遥测 |
| `viewport.js` | 视口：点选 / gizmo（TransformControls r186）/ 吸附 / 聚焦 / 三视图 |
| `presets.js` | 预置场景（空场景、斜面小球），与 UI/Agent 同一条 createEntity 路径 |
| `parse-schema.js` | 题图解析结果零信任规范化 + 建场计划（planToOverrides） |
| `workbench.js` | UI 接线 + `window.MECH` 白名单编程接口（组件/变换/物理/重力/解析元数据） |

物理与视觉分离：每个实体 = 渲染网格 + 碰撞形状 + 质量动力学参数 + 刚体类型（动态/固定/仅视觉），全部可序列化。

## 教学预置场景（P2，走通用场景系统）

顶栏"预置场景"下拉（列表持续扩充：斜面小球 / 动量守恒）：

- **动量守恒（一维对撞）**：光滑地面 + 两球，质量/初速度/弹性检查器可编辑。底栏"守恒"开守恒量条
  （总动量/总动能实时、碰撞时刻、p 前/后、动量误差、KE 前/后）；底栏"矢量"开速度向量箭头、
  "轨迹"开轨迹线（编辑态显初速度，运行态显当前速度）。
- **天体运动（恒星+卫星）**：自写 velocity-Verlet n 体引力积分（非预设圆线，能量/角动量长期有界）。
  守恒量条 astro 模式：机械能/角动量及漂移、周期、偏心率、rmin/rmax。底栏"轨迹"开轨道线。
  渲染尺寸与引力质量分离（物理实体与视觉实体分离）；doc.G 为场景引力常数。
- **角动量守恒（转台+径向滑块）**：转台自旋 + 滑块沿径向滑槽（prismatic joint，槽内无摩擦）惯性外滑，
  I 增 ω 减 L 守恒。守恒量条 rotation 模式：ω/转动惯量 I/角动量 L 及漂移/动能/滑块半径/外力矩状态。
  转台带辐条（转动可视化）；实体级 `joints` 字段 = 通用约束通道（场景文档可序列化）。
- **绳/弹簧约束**：连接类组件（`rope` 仅拉不推 / `spring` 胡克定律）——手动=选中两实体点目录（自动定长），
  Agent/解析=attaches 索引语义自动连接；**弹簧振子拍题九步**（简谐振动 T=2π√(m/k) 理论 vs 峰值间隔法实测）。
- **复摆（铰链杆）**：`hinge` 铰链组件（revolute joint）+ 刚性杆绕端点摆动，
  周期 T=2π√(2L/(3g)) 解释对照（解 wrap+滑动平均周期检测）。球体支持**滚动阻力**参数（rollResist）。
- **阿特伍德机（定滑轮）**：`pulley` 组件 + `onPulley` 球对约束（绳长守恒逐步投影，质量反比分配 + PBD 速度一致性），
  张力 T 与加速度 a=(m1−m2)g/(m1+m2) 解释对照。吸附按钮循环支持**端点/表面/中心**吸附类型。
- **管道轨道（经典演示迁移）**：半管滑道+竖直环轨组件化（`track` 组件 + `onTrack` 中心线解析约束，光滑无摩擦），
  铬球自由释放走完下坡+环轨（Goal 第二节"轨道场景迁移为可复用预置"的兑现）。

**教学叠加层**（底栏开关）：速度向量箭头、**受力/加速度箭头**（重力红 + 接触合力绿 + 加速度青，速度差分反推）、
轨迹线、守恒量条（三模式：动量/天体/转动，各含 **KE/PE 分色能量堆叠条** + 保持率比例条）、
碰撞时刻标记环（碰撞点扩散淡出）、**时间曲线面板**（选中体速率/高度 + 系统动能三色折线）。
**选择**：点击单选、shift 加选、"框选"模式橡皮筋多选、Del 多选删除；大纲双击重命名、"锁"防误选。
**视图**：透视/正交相机切换；gizmo 移动/旋转/**缩放**（视觉缩放，碰撞体不变已标注）；**录制/回放**（帧序列）；
**受力分解**（"分解"按钮：支持力 N + 摩擦力 f 分列箭头，斜面场景）；**单位标尺**读数（网格 1 格=1 m + 视野宽）；
组件目录**搜索/最近使用/收藏**。差距盘点：`docs/GAP-MATRIX.md`。
