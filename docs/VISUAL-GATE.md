# 交付前视觉闸门（R6-037）

背景：三轮用户实锤（球穿轮飞出画框 / 绳完全不可见 / 滑轮轮面躺平）全发生在「用户看得见」层——
物理/断言层全绿证明不了用户看到的东西对。本闸门是交付任何视觉物料前的必经关卡。

## 一、自动闸门（p49，必跑）

    cd tools/ui-test && MECH_BASE=http://127.0.0.1:8722 node p49-visual-audit.mjs

覆盖全部预置场景 ×（初始+运行3s）+ Agent 建场链，四类探针：
- **A 出画**：所有动态体 NDC |x|,|y| ≤ 1.35（初始与运行 3s 后两拍）
- **B 连接可视化**：onPulley 球对必须有跨绳网格（atwoodRope≥3）；全实体必须有网格
- **C 画面非退化**：画布（vp.render() 现渲后读回）320×180 采样 mean>4 且亮像素(≥40)≥50
- 豁免必须显式写入测试并注明原因，不许静默

## 二、视觉终验（有图/视频交付时，必做）

抽 ≥2 帧问视觉模型，**问对立问题，不问引导问题**：
- ✗「画面里有什么物体」（会被脑补：躺平圆盘被描述成立式滑轮、不存在的绳被描述出来——实测两真 bug 从此漏过）
- ✓「滑轮轮面是正对镜头的立式轮，还是水平躺平的圆盘？」
- ✓「能否看到绳：两侧竖直绳段在哪里？轮顶有无跨接弧？」
- ✓「物体是否都在画面内/贴边？哪一侧贴边？」
- ✓「逐字转录字幕」

## 三、视频物料（有录像时）

- MediaRecorder 的 webm 头缺 duration → `ffmpeg -i in.webm -c copy out.webm` remux
- 高光剪接口诀：**头部短（≤5s）+ 动作前一镜到底**，别拼三段；建场点用
  `ffmpeg -vf "select='gt(scene,0.06)',metadata=print"` 定位

## 本闸门咬出并修复的实账（2026-10-25 首跑）

弹丸 r≤0.06 v=15 穿木块（Rapier CCD 实测不生效→自适应细分步）/ 预置 atwood 无限转出画
（行程端定格去 teach 门）/ waveRoad 穿面坠 −11m（trimesh 安全底衬）/ projectile·curvedRace·
rangeAngles 落点滚出镜头（相机+挡板）/ 八场景 focusScene 被 30m 地面拉远成芝麻（地面切片取景）/
galileoDrop 等物件暗淡（同前项根因）。
