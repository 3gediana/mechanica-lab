## NORTH STAR

学生拍一道题，得到的是一堂 60 秒的微型物理课：先看懂题（拆题简报），再看懂装置（一比一还原，绳是绳轮是轮），再看懂过程（关键点自动慢放/定格，公式与画面里正在发生的事实时对上，矢量、曲线、数字代入多通道齐上），最后能自验（对照理论、变式对比、可选小测）。老师拿到的是能直接放课堂的放映片。这堂课由 agent 自己搭、自己检查、自己修，不需要任何人在旁边兜底。

## DELIVERY HORIZON（三战区，A 为主 B 为地基 C 为节奏）

### A. 教学能力跃迁（用户点单主体）

- **A1 拆题简报**：建场前 Agent 面板呈现结构化简报——已知量/未知量/考点/解题路线，来自解析已有的 keyPoints/unknowns 字段，可视化成分步条目（步骤条/清单卡），不是灰字墙；评审表单里可勾选采纳。
- **A2 讲解表达多通道化（≥4 条新通道，每条绑定明确教学价值，触发点挂 teach moment）**：
  - **公式实时代入卡**：teach 卡在 title/formula 之下加「代入行」，用场景文档真实参数确定性算出（如 a=(3−2)×10/(3+2)=2.00 m/s²），与解释器同源，**禁止模型编数字上屏**；
  - **矢量/曲线联动聚光**：contact 等时刻自动高亮相关叠加层——受力箭头闪烁强调、曲线面板游标跳到该瞬间并打标，让「此刻画面在干嘛」可读；
  - **语音旁白**：teach 卡文本走 Web Speech 中文 TTS；尊重全局静音，TTS 不可用静默降级为纯视觉；
  - **对比变式（一题多变）**：讲解完成后从当前场景文档**规则化派生**一个变式（无摩擦版/质量减半版/初速加倍版，改文档参数非模型调用），一键切换原题↔变式对比结论——「一题多变」是物理教学核心手法。
- **A3 moment 类型扩展 ≥3 种**，覆盖已支持题型族：turn（水平折返/弹簧最大伸缩 stretchMax——弹簧长度极值，_syncLinks 已有长度）、leaveSurface（接触结束即抛离——碰撞事件已有）、equilibrium（静息钳制触发——R6-025 已有判据）、sinkFloat（浮沉平衡——R6-023 液体链已有）。每种配事件检测 + 单测 + UI 断言。
- **A4 讲解节奏分级**：moment 类型 → 暂停/慢放时长策略（contact=定格约 2s、highest=更慢更长、release=短提示），不再全场景一刀切 1.6s；策略表可测。
- **A5 课堂放映模式**：一键「放映」=自动重置→播放→每个 teach moment 定格数秒（浮卡+字幕已具备）→全程录屏成片，产出可直接进课堂的讲解片；仅在放映模式内做镜头推近（不劫持交互相机）。
- **A6 教学链题型覆盖 ≥6 族**（atwood/斜面/抛体/单摆族/弹簧族/动量），每族 fixture 金标 + 真实模型抽查 teaching 字段质量各 1 次。

### B. Agent 自检自修闭环（信任地基——用户「我不信你了」的彻底回应）

- **B1 建场后 in-app 自检**：把 p49 四类探针移植进应用本体——出画（NDC）/连接可视化（atwoodRope 等）/画面非退化（现渲采样）/物理合理性（**新增第四种**：观察量 vs 理论量级粗对账，如 a 与 (m1−m2)g/(m1+m2) 偏差>30% 即报）。建场完成自动跑，结果进 agentOps 与任务徽标；p49 探针已是页内函数，移植成本低。
- **B2 自动修复循环**：自检不过 → 规则化修复（重取景/包络补拍/布局修正/参数回退）→ 复检，至多 2 轮；仍失败如实报「建场自检未过 + 原因 + 建议人工项」，**不许静默放过**。
- **B3 注入故障验证**：把 p49 首跑咬出的 9 类真问题做成可注入故障，验证闭环能自动修 ≥4 类（测试侧证据）。

## PRODUCT COMPLETENESS（本项目「完整」的含义）

- **学生主路径**：上传/拍照→（等待有进度可感知）→拆题简报→评审修正→建场（自检过，画面里每个装置件可见可懂）→运行（关键点多通道讲解，节奏有起伏）→解释对照（数字可复算）→变式对比→放映片可下载。每步有进行中/成功/失败三态。
- **老师主路径**：预置场景/自搭场景同样享受 A2~A5 讲解能力（教学链读场景文档，不挑实体来源）；放映片可直接课堂播放。
- **失败/边界路径**：解析超时自愈（已有）、自检不过诚实降级、无 key 边界（fixture 明确标注）、TTS 不可用静默降级、变式生成失败回原题。
- **不许出现**：讲解卡与画面脱节（说的公式对应不上画面正在发生的事）、假数字、模型幻觉公式未经确定性校验上屏、教学通道只有 happy path。

## QUALITY BAR（红线，违反=返工）

- 一切上屏数字（解释/代入行/变式）必须确定性可复算，与 explain.js 同源；禁止 LLM 生成数字。
- UI 设计语言不变：仪器级暗色、琥珀唯一强调色、无渐变无玻璃拟态无 emoji、动效只做状态反馈；新教学通道视觉必须融入现有语言，样张过视觉门。
- 模型输出字符串上屏一律 textContent（防注入）。
- **真实还原非数学等价**：慢放/定格/聚光是观察手段，不得改动物理演化本身。
- 每个新通道必须答上「它让学生看懂了什么原来看不懂的东西」；纯装饰通道砍掉。
- 测试断言不许为过而弱化；flaky 修根因，不许加 sleep 凑。
- 并发子代理 ≤2 路（用户令）。

## OPEN CREATIVE MANDATE（惊喜预算）

每个大战区完成时主动尝试 ≥1 个高上限创意（不合适就删并说明理由）：

- **黑板时刻**：teach 定格瞬间在场景上叠 2D 黑板式受力图/示意图——把 3D 画面翻译回课本图语言（学生看不懂 3D 对应课本哪张图，是真实痛点，也是「一块圆盘看不懂」的终极回应）；
- **互动小测**：放映结束出 1~2 道从题面确定性派生的数值代入题，学生答对才算学完；
- **镜头语言**：放映模式中 contact 时刻自动推近特写（仅放映模式）；
- **套题连堂**：一次上传含 2~3 小问的复合题，agent 拆成连贯分幕演示。

判断标准：是否让学生/老师获得原来没有的理解；是否与仪器级气质连贯；是否挤占核心打磨（挤占就砍）。
