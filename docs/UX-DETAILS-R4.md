# UX 细节台账（用户硬要求：150 条真实可感细节，只优化已有功能不堆新功能）

范围：本轮（Round 42）实装。每条=一处独立可感的行为/反馈/文案调整。

## 波1 场景管理（SCN，用户点名：保存/改名/标签/Agent 自动标签）

- D1 [保存] 「保存」=存入浏览器场景库（localStorage 多场景，替代纯文件下载）
- D2 [快捷键] Ctrl+S 语义升级为「保存到场景库」
- D3 [状态] 未保存改动→头部琥珀脏点亮起（commitChange 全链挂脏）
- D4 [状态] 保存/打开/新建后脏点熄灭
- D5 [库] 场景正文快照按 sceneId 随保存写入（库「打开」有所指）
- D6 [打开] 「打开」=场景库弹层（裸文件选择收编进库内「导入文件」）
- D7 [库] 检索：名称+标签联合过滤，Enter 打开第一个结果
- D8 [库] 排序：最近更新/名称（zh locale）/实体数
- D9 [库] 卡片缩略图=保存瞬间真实视口截图（160×90 jpeg cover）
- D10 [库] 当前场景卡高亮（▶+琥珀描边）
- D11 [库] 双击卡片名=行内改名（Enter/Esc），当前场景同步头部
- D12 [库] 标签 chips 点 × 移除（同步 doc.tags）
- D13 [库] 「+标签」行内输入（Enter 提交/Esc 取消，≤12 字）
- D14 [库] 「副本」一键克隆条目
- D15 [库] 「导出」单条 JSON（当前场景直出/历史条目自动存档兜底）
- D16 [库] 工具条「导出当前」保留旧「保存为文件」工作流
- D17 [库] 「导入文件」从库内导入 JSON
- D18 [库] 删除二次确认=按钮变身「确认删?」（2.6s 复原，不用原生弹窗）
- D19 [库] 删除当前条目自动解绑 sceneId
- D20 [库] 空库引导文案
- D21 [库] Esc/点遮罩关闭；Ctrl+O 打开
- D22 [库] 容量 40 条上限，超限让位并报出场景名
- D23 [Agent标签] 解析计划自动派生标签（题型+实体+环境关键词，≤6 个；图片/文字/修订三通道全接）

- D25 [改名] 场景名聚焦全选
- D26 [改名] Esc 还原；空名回落原名
- D27 [打开] 文件载入报实体数+「保存继续更新库条目」
- D28 [库] 相对时间（刚刚/N 分钟前/…）+来源徽标
- D29 [保存] 保存 toast 报出标签
